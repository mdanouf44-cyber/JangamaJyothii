## 📧 **PART 1: Adding Business Email to Gmail**

### **Step 1: Access Gmail Settings**

1. **Open Gmail** in your browser
2. **Look for the gear icon ⚙️** in the top-right corner
3. **Click the gear icon**

```
🖼️ SCREENSHOT DESCRIPTION:
- Gmail interface with gear icon highlighted
- Settings dropdown menu visible
- "See all settings" option at the bottom
```

4. **Click "See all settings"** (at the bottom of the dropdown)

### **Step 2: Navigate to Accounts Tab**

```
🖼️ SCREENSHOT DESCRIPTION:
- Gmail settings page open
- Multiple tabs visible: General, Labels, Inbox, Accounts and Import, etc.
- "Accounts and Import" tab highlighted
```

1. **Click on "Accounts and Import" tab**
2. **You'll see several sections on this page**

### **Step 3: Add Mail Account**

```
🖼️ SCREENSHOT DESCRIPTION:
- "Accounts and Import" page showing
- Section "Check mail from other accounts"
- "Add a mail account" link visible
- Other sections like "Send mail as" also visible
```

1. **Find the section**: "Check mail from other accounts"
2. **Click "Add a mail account"**

### **Step 4: Enter Your Business Email**

```
🖼️ SCREENSHOT DESCRIPTION:
- Pop-up window titled "Add a mail account"
- Text field for email address
- "support@shreejangamajyothi.com" entered in the field
- "Next" button at the bottom
```

1. **Enter**: `support@shreejangamajyothi.com`
2. **Click "Next"**

### **Step 5: Choose Import Method**

```
🖼️ SCREENSHOT DESCRIPTION:
- New screen with two radio button options:
- ○ Import emails from my other account (POP3)
- ● Link accounts with Gmailify (recommended)
- "Next" button at bottom
```

1. **Select**: "Import emails from my other account (POP3)"
2. **Click "Next"**

### **Step 6: Configure Server Settings**

```
🖼️ SCREENSHOT DESCRIPTION:
- Form with multiple fields:
- Username: support@shreejangamajyothi.com
- Password: [password field]
- POP server: mail.shreejangamajyothi.com
- Port: 995
- Checkboxes for SSL and other options
```

**Fill in these details exactly:**
```
Username: support@shreejangamajyothi.com
Password: [your email password from cPanel]
POP server: mail.shreejangamajyothi.com
Port: 995
✅ Always use a secure connection (SSL) when retrieving mail
✅ Label incoming messages as: support@shreejangamajyothi.com
✅ Archive incoming messages (Skip the Inbox)
```

3. **Click "Add Account"**
